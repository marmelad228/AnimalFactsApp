# Animal Facts App
Проект консольного приложения на языке C#, которое умеет запрашивать интересные факты о кошках и собаках через публичные API, а также собирать статистику текущей сессии.

# Что умеет программа:
1. Запрос фактов о кошках — связывается с Cat API, забирает случайный текстовый факт.
2. Запрос фактов о собаках — связывается с Dog API, обрабатывает полученный массив данных и выводит текст.
3. Цветной интерфейс — для удобства главное меню подсвечено зелёным цветом, а факты о собаках выводятся жёлтым.
4. Статистика сессии — программа запоминает, сколько раз за текущий запуск пользователь посмотрел кошек и собак, и показывает общий итог.

# Использованные эндпоинты (REST API):
* Facts о кошках: https://catfact.ninja/fact
* Facts о собаках: https://dog-api.kinduff.com/api/facts

Взаимодействие с серверами реализовано асинхронно с помощью класса `HttpClient`, данные получаются из формата JSON. Также добавлена базовая обработка ошибок на случай сбоя сети.

#  Как устроен проект:
Разработка велась по правилам коммерческой командной разработки с разделением на ветки:
* `master` — основная стабильная ветка проекта.
* `feature-ui-fix` — ветка, в которой настраивались цвета консоли и форматировался текст.
* `feature-statistics` — отдельная ветка, где писалась логика счётчиков и создавался 4-й пункт меню. В итоге она была успешно слита в master через Pull Request на GitHub.
